# Technical B2B Architecture & Industrial Specifications

> **Arquitectura de Fichas Técnicas, Parámetros Industriales y Flujo RFQ Textil**

Esta skill establece la taxonomía técnica, parámetros de laboratorio y modelos de datos para compradores industriales B2B (hilanderías, tejedurías de punto y plano, cordonerías, agroindustria y empaque).

---

## 🧵 Taxonomía Técnica de Productos (Industria Monir)

Toda especificación de producto debe utilizar nomenclatura industrial normalizada:

### 1. Algodón Industrial
- **Clasificación:** Fibra virgen / fibra recuperada seleccionada / mezclas técnicas.
- **Parámetros clave:** Longitud de fibra (mm / pulgadas), índice Micronaire (finura/madurez), porcentaje de impurezas/materia vegetal, grado de color y resistencia específica (g/tex).
- **Presentación:** Fardos prensados y flejados de alta densidad (180–220 kg aprox.), enfundados en rafia impermeable.

### 2. Hilo de Alta Tenacidad
- **Titulación:** Sistema Inglés (`Ne`) o Métrico (`Nm`), títulos estándar para urdimbre y trama.
- **Parámetros clave:** Tenacidad a la rotura (cN/tex), torsión por metro (`TPM`) y sentido (`Z` o `S`), coeficiente de variación de masa (`CV%`), elongación a la rotura (`%`).
- **Presentación:** Conos de cartón/plástico estándar industrial (1.5 kg a 2.5 kg), cajas paletizadas con flejado cruzado.

### 3. Pavilo Homogéneo
- **Tipología:** Pavilo crudo para mechas, torcidos industriales, empaques y manualidades técnicas.
- **Parámetros clave:** Gramaje lineal (g/m), número de cabos/hebras, uniformidad sin nudos espurios, absorción y combustión homogénea.
- **Presentación:** Madejas, bobinas cilíndricas o rollos industriales continuos.

## 📋 Estructura de Solicitud de Cotización (Mesa RFQ B2B)

El formulario de contacto debe actuar como una orden de requerimiento técnico formal, solicitando datos operativos clave:
1. **Línea de Interés:** Algodón / Hilo / Pavilo / Mezcla a medida.
2. **Volumen Proyectado:** Tonelaje mensual o tamaño de lote inicial (mínimo por fardos/pallets).
3. **Especificación Técnica Deseada:** Título, calibre, color crudo/teñido o aplicación final (e.g., tejeduría circular, cordonería, encuadernación, mechas).
4. **Destino Logístico:** Ciudad / Puerto / Planta receptora para estimación de flete y despacho.
